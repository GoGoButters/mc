# Клавиши по модам

Клавиши можно поменять в «Настройки → Управление». Ниже — клавиши, которые вводит сборка; обычные клавиши Minecraft (чат, прыжок и другие) остаются прежними.

## Голос (Simple Voice Chat)

| Клавиша | Что делает |
|---|---|
| <KeyBind id="key.push_to_talk" /> | Говорить (держать) |
| <KeyBind id="key.whisper" /> | Шёпот |
| <KeyBind id="key.voice_chat" /> | Окно голосового чата |
| <KeyBind id="key.voice_chat_settings" /> | Настройки голосового чата |
| <KeyBind id="key.voice_chat_group" /> | Групповой чат |
| <KeyBind id="key.mute_microphone" /> | Отключить микрофон |
| <KeyBind id="key.disable_voice_chat" /> | Выключить голосовой чат |

## Бой и снаряжение

| Клавиша | Что делает |
|---|---|
| <KeyBind id="keybinds.combat_roll.roll" /> | Рывок-кувырок (Combat Roll) |
| <KeyBind id="key.backpacked.open_backpack" /> | Открыть рюкзак |
| <KeyBind id="key.backpacked.open_management" /> | Управление рюкзаком |
| <KeyBind id="key.corpse.death_history" /> | История смертей (Corpse) |

## Колония и войны

| Клавиша | Что делает |
|---|---|
| <KeyBind id="key.recruits.command_screen_key" /> | Командование рекрутами |
| <KeyBind id="key.recruits.team_screen_key" /> | Фракция и дипломатия |
| <KeyBind id="key.recruits.map_screen_key" /> | Карта территорий |
| <KeyBind id="key.minecolonytax.open_tax_gui" /> | Казна колонии |

## Интерфейс

| Клавиша | Что делает |
|---|---|
| <KeyBind id="key.jade.show_overlay" /> | Показать/скрыть подсказку Jade |
| <KeyBind id="key.jade.show_details" /> | Детали (состав, энергия) |
| <KeyBind id="key.jade.show_recipes" /> | Показать рецепт блока/существа |
| <KeyBind id="key.jade.show_uses" /> | Показать применение блока/существа |

Полный список клавиш JEI — в разделе «JEI и рецепты».
