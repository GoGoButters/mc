# Путь правителя

Странник, не всякий пришелец остаётся чужим. Здесь, у деревень и колоний, ты можешь стать своим: заслужить доверие жителей, поставить собственную колонию, поднять казну и налоги и повести за собой людей — от первой хижины до королевства.

Этот путь строится из трёх опор: **люди** (деревня MCA), **колония** (MineColonies) и **война с торговлей** вокруг них. Раздел ведёт по порядку: сначала познакомься с людьми, затем поставь свою колонию рядом, свяжи их вместе, накорми, защити и реши, с кем воевать, а с кем торговать.
