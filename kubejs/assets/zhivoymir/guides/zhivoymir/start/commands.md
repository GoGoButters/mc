# Голос, клавиши и команды

## Голосовой чат

- <KeyBind id="key.push_to_talk" /> — говорить (держи нажатой).
- <KeyBind id="key.voice_chat" /> — окно голосового чата: громкость, микрофон, группы.

Жители, колонисты и бог слышат тебя и отвечают голосом. Жителю — смотри на него или назови его по имени или профессии. Богу — начни с «Боже» или «Господи».

## Клавиши

| Клавиша | Что делает |
|---|---|
| <KeyBind id="key.recruits.command_screen_key" /> | Командование рекрутами |
| <KeyBind id="key.recruits.team_screen_key" /> | Фракция и дипломатия |
| <KeyBind id="key.recruits.map_screen_key" /> | Карта территорий |
| <KeyBind id="key.minecolonytax.open_tax_gui" /> | Казна колонии |

Клавиши можно поменять в настройках управления.

## Команды

| Команда | Что делает |
|---|---|
| `/guide` | Снова получить эту книгу |
| `/wnt checktax`, `/wnt claimtax` | Посмотреть и забрать налоги |
| `/wnt taxpolicy set <политика>` | Налоговая политика |
| `/wnt raid`, `/wnt wagewar`, `/wnt besiege` | Набег, война, осада |
| `/wnt peace …`, `/wnt payextortion` | Мир, выплата дани |
| `/wnt vassalize`, `/wnt vassals` | Вассалы |
| `/wnt faction …` | Фракции колоний |
| `/wnt help` | Справка по всем командам War 'N Taxes |
| `/pvp` | Дуэль на арене |

## Золотые правила

1. Не вреди жителям и колонистам.
2. Ставь колонию рядом с деревней, но не вплотную.
3. Защищай деревню и зарабатывай её доверие — тогда её люди переедут к тебе.
4. Сначала жильё, еда и стража, потом армия.
5. Изумруды зарабатываются трудом: торговля, задания, колония.
6. Построй алтарь и не забывай о боге.
