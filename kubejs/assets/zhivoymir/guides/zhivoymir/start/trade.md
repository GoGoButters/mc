# Торговля

## С жителями

У жителей деревни можно покупать и продавать товары за изумруды (кнопка **Торговать** в меню жителя). У каждой сделки есть предел, а запасы пополняются пару раз за игровой день.

## Доски заданий

<ItemImage id="bountiful:bountyboard" />

В деревнях стоят **доски заданий**. На них — поручения: принести вещи, убить чудовищ. В награду — изумруды (1–4 за задание) и другие ценности. У заданий есть срок. Новые появляются примерно **раз в 5 минут**.

## Торговая станция и рынок (Trade Post)

Постройки колонии для торговли:

- **Рынок** — продавец продаёт лишнее из склада заезжим покупателям за **торговые монеты**.
- **Торговая станция** и смотритель станции связывают твою колонию **торговыми путями** с другими колониями: по железной дороге, по дороге, по воде, по воздуху. По воздуху быстрее всего.
- Ещё есть аванпост, курорт, переработка и зоомагазин.

Торговые монеты — отдельная валюта, на изумруды они не меняются.

## Монеты Create (Numismatics)

Для торговли между игроками есть **монеты Numismatics**, банковские счета и торговые автоматы. Своих монет у игроков на старте нет: игроки сами договариваются о ценах и курсе.
