# Структуры: что и где искать

## YUNG's Better Structures

Переработанные ванильные структуры — больше уровней, ловушек и наград. ID в таблице нужны для команды `/locate structure <id>` — она доступна только администратору; обычному игроку структуры предстоит искать самому.

| Структура | ID для /locate |
|---|---|
| Данжи (обычные, скелетные, зомби, паучьи, незерские) | `betterdungeons:small_dungeon` и др. |
| Пустынный храм | `betterdeserttemples:desert_temple` |
| Храм джунглей | `betterjungletemples:jungle_temple` |
| Заброшенные шахты (по биомам) | `bettermineshafts:mineshaft_*` |
| Крепость Незера | `betterfortresses:fortress` |
| Океанский монумент | `betteroceanmonuments:ocean_monument` |
| Крепость (Stronghold) | `betterstrongholds:stronghold` |

Край тоже переработан: Better End Island меняет сам остров Края.

## Dungeons & Taverns

Десятки новых структур — таверны, руины, сторожевые башни, лагеря и другие. Почти все ID начинаются с `nova_structures:`, например `nova_structures:tavern_acacia`.

## Деревни (ChoiceTheorem's Overhauled Village)

Деревни и аванпосты разбойников подогнаны под биомы: `ctov:village_*` и `ctov:pillager_outpost_*`.

## Лут: у каждого свой (Lootr)

Сундуки во всех структурах — **особенные**: каждый игрок видит в них свой собственный лут. Один сундук могут взять несколько человек, и никому не придётся делиться. Пустой сундук для другого игрока может быть полным для тебя — не проходи мимо.
