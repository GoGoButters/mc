# Create: кинетика

## Что даёт

Create — кинетическая основа техники. Здесь нет магии: всем правит **вращение**. Валы и шестерни передают его дальше и приводят в движение мельницы, прессы и воздуходувки.

Основные блоки:

- <ItemLink id="create:hand_crank" /> — Рукоятка, первый источник вращения;
- <ItemLink id="create:cogwheel" /> и <ItemLink id="create:large_cogwheel" /> — шестерни, передают вращение между валами;
- <ItemLink id="create:powered_shaft" /> — Силовой вал, ведёт вращение вдаль;
- <ItemLink id="create:mechanical_bearing" /> — Механический вращатель;
- <ItemLink id="create:mechanical_press" /> — Механический пресс;
- <ItemLink id="create:crushing_wheel" /> — Дробильное колесо, дробит руду и сырьё;
- <ItemLink id="create:steam_engine" /> — Паровой двигатель, источник вращения посерьёзнее рукоятки;
- <ItemLink id="create:track" /> — Железнодорожный путь;
- <ItemLink id="multipiston:multipistonblock" /> — Мультипоршень: двигает целые блоки «гусеницей», настройки — в его меню.

## Первый шаг

<ItemImage id="create:wrench" />

**Гаечный ключ** (<ItemLink id="create:wrench" />) — первый инструмент инженера. Им крутят механизмы, разбирают постройки и меняют режимы. Рецепт прост: две золотые пластины, шестерня и деревянный стержень.

<RecipeFor id="create:wrench" />

Первое вращение даёт **рукоятка** (<ItemLink id="create:hand_crank" />): ПКМ крутит её против часовой стрелки, Sneak+ПКМ — по часовой. Приставь её к шестерне — и путь вращения начат.

## Как учиться

У Create есть **поучительные сцены**: зажми **W** и нажми ПКМ по механизму — мир покажет тебе, как он устроен. Своя сцена есть у пресса, дробилки, вращателя, мультипоршня и почти каждого механизма. Просматривай их всякий раз, когда берёшься за незнакомый блок.

## Связи с другими модами

- **Электричество и валюта** — рядом, через Create Crafts & Additions и Numismatics (см. следующую страницу).
- **Рельсы** Create — свои поезда; для больших дорог и составов смотри Railcraft (railcraft.md).
- Обычный порядок инженера: **Create → Mekanism → AE2** — сначала кинетика, потом химия и энергия, потом автоматизация.
- Механизмы Create работают сами, пока ты занят деревней и колонией.

## Где смотреть подробнее

- Ponder-сцены по каждому механизму.
- **JEI** — рецепты всех блоков и деталей.
- Встроенные руководства Create, если они есть под рукой.

> Вращение, начатое рукой, питает целый завод. Путь странника тоже начинается с одного шага.
