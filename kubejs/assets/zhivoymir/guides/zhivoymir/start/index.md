# Живой мир: Летопись странника

Странник, ты пришёл в мир, где всё дышит. Здесь есть деревни, где у каждого жителя своё имя, семья и характер. Есть колонии, которые ты строишь своими руками. И есть **бог**, который видит твои поступки.

Эта книга — твой первый спутник. Читай разделы по порядку или возвращайся к ним по ходу игры. Если потеряешь книгу — введи в чат `/guide`.

## Твой путь

1. **Найди деревню** — там люди, торговля и защита.
2. **Поставь колонию неподалёку** — стартовый лагерь уже лежит у тебя в сумке.
3. **Свяжи деревню и колонию** — переселяй жителей, охраняй деревню.
4. **Найди общий язык с богом** — молись, построй алтарь, приноси дары.
5. **Познай соседей** — торговля, союзы, налоги и войны.
