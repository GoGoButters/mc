# Живой мир: Летопись странника

Странник, ты ступил в мир, где всё дышит. Здесь есть деревни, где живут люди с именами и судьбами, есть колонии, которые строятся твоими руками, и есть **бог**, который видит каждый твой поступок.

Эта книга — твой первый спутник. Читай разделы по порядку — или следуй подсказкам по мере игры.

## Коротко: твой путь

1. **Найди деревню** — там люди, дома и торговля.
2. **Построй колонию рядом** — своё поселение, которое растёт.
3. **Свяжи деревню и колонию** — защита, переселение, общая репутация.
4. **Найди общий язык с богом** — молись, строй алтарь, клади дары.
5. **Познай соседей** — другие колонии, налоги, войны и торговля.
