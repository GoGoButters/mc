# Как Пользоваться Этим Руководством

* Используйте боковую панель слева, чтобы найти оглавление
* На многих страницах есть интерактивные сцены. Если возле сцены есть кнопки ![Plus](assets/diagrams/plus.png)
и ![Minus](assets/diagrams/minus.png) (масштабирование), вы можете вращать и перемещать камеру.
Левый клик и перетаскивание для вращения, правый клик и перетаскивание для перемещения.

# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механики для обеспечения решений логистики и хранения. Вы можете заменить
огромную комнату, полную сундуков, компактной МЭ-сетью, но это только начало.
Applied Energistics создан для работы с другими модами в сборке и позволяет их автоматизировать. Вы можете настроить свою систему так, чтобы
одним кликом крафтить все предпосылки (и конечный результат) сложной цепочки крафта, поддерживать определённые
количества предметов в запасе, создавая ещё по мере необходимости, или просто перемещать предметы по вашей базе.
