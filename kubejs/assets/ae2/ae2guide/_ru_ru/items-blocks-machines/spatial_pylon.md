# Пространственная опора

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

Пространственная опора используется в [пространственном вводе-выводе](../ae2-mechanics/spatial-io.md) для генерации пространственного поля и определения объёма,
на который будет оказано воздействие.

Каждая непрерывная линия опор использует 1 [канал](../ae2-mechanics/channels.md)

Линии опор должны быть длиной не менее 2 блоков, чтобы функционировать.
