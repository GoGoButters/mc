# МЭ-Сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ-Сундук работает как миниатюрная сеть с <ItemLink id="terminal" />, <ItemLink id="drive" /> и <ItemLink id="energy_acceptor" />.
Хотя его можно использовать как крошечную сеть хранения, его вместимость — всего одна [ячейка хранения](../items-blocks-machines/storage_cells.md),
что ограничивает его полезность в этом качестве.

Вместо этого он полезен для взаимодействия именно с ячейкой хранения, установленной внутри. Его встроенный терминал видит и открывает
только предметы в установленном накопителе, тогда как [устройства](../ae2-mechanics/devices.md) общей сети могут получить доступ к предметам в любом [сетевом хранилище](../ae2-mechanics/import-export-storage.md),
включая МЭ-сундуки.

У него 2 разных интерфейса, и он имеет направленные стороны для транспортировки предметов. Взаимодействие с верхним терминалом открывает встроенный терминал. Через эту грань предметы можно вставлять
в установленную ячейку хранения, но извлекать нельзя. Взаимодействие с любой другой гранью открывает интерфейс со слотом для ячейки хранения
и настройками приоритета. Ячейку можно вставлять и извлекать средствами предметной логистики только через грань со слотом для ячейки.

Его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

У него есть небольшой буфер хранения энергии AE, поэтому если он не подключён к сети с [энергоячейкой](../items-blocks-machines/energy_cells.md),
при одновременном вводе или выводе слишком большого количества предметов он может «просесть» по питанию.

Терминал можно покрасить с помощью <ItemLink id="color_applicator" />.

## Настройки

МЭ-Сундук имеет все те же настройки, что и <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />.
Однако он не поддерживает <ItemLink id="view_cell" />.

## Светодиоды состояния ячеек

На ячейках в сундуке есть светодиод, показывающий их состояние:

| Цвет  | Состояние                                                                        |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пустая                                                                             |
| Синий   | Имеет некоторое содержимое                                                                |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, больше предметов вставить нельзя |
| Чёрный  | Нет питания или накопитель не имеет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритеты можно задать, щёлкнув по гаечному ключу в правом верхнем углу интерфейса слота ячейки.
Предметы, поступающие в сеть, первым делом будут направляться в хранилище с наивысшим приоритетом. Если два хранилища или ячейки имеют одинаковый приоритет,
то при наличии предмета в одном из них предпочтение будет отдано этому хранилищу перед любым
другим. Любые [разделённые](cell_workbench.md) ячейки считаются уже содержащими предмет
при одинаковой группе приоритета с другими хранилищами. Предметы, удаляемые из хранилища, будут
извлекаться из хранилища с наименьшим приоритетом. Благодаря этой системе приоритетов по мере добавления и извлечения предметов
из сетевого хранилища хранилища с более высоким приоритетом будут заполняться, а с более низким — опустошаться.
