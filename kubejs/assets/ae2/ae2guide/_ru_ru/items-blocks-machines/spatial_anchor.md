# Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Сеть AE2 должна быть загружена в чанки, чтобы любое из её [устройств](../ae2-mechanics/devices.md) могло функционировать, а если загружена только её часть,
она может работать некорректно. Пространственный якорь решает эту проблему. Он принудительно загружает чанки, которые занимает его сеть.
Одного кабеля, протянутого через границу чанков, достаточно, чтобы загрузить новый чанк.

Он распространяет свою «загрузку» через [квантовые мосты](quantum_bridge.md), но не между измерениями, поэтому если у вас
есть квантовый мост в Незер, вам нужен пространственный якорь на сети в вашей базе и на сети в Незере.

По умолчанию он также включает случайные тики в загруженных чанках; это можно отключить в конфигурации ae2.

Его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />, если по какой-то причине вы хотите это сделать.

## Настройки

*   Пространственный якорь предоставляет доступ к глобальной настройке просмотра энергии в AE или E/FE.
*   Можно отображать голограмму в мире, показывающую загружаемые чанки.

## Энергия

Пространственный якорь будет использовать [энергию](../ae2-mechanics/energy.md) по этой формуле:

e = 80 + (x\*(x+1))/2

где x — количество загружаемых чанков
