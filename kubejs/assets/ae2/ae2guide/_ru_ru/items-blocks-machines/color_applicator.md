# Приклад с краской

<ItemImage id="color_applicator" scale="4" />

Приклад с краской используется для окраски окрашиваемых блоков, таких как [кабели](cables.md), шерсть, терракота, стекло и бетон. Он использует
[красящие шары](paintballs.md) или красители, а снежки можно использовать для очистки цвета с кабелей и пятен краски с блоков.

Его энергию можно перезарядить в <ItemLink id="charger" />.

Приклады с краской работают как [ячейки хранения](storage_cells.md), и их запас краски проще всего заполнить, поместив
приклад в слот ячейки хранения в <ItemLink id="chest" />

Щёлкните правой кнопкой мыши по цели, чтобы нанести выбранный цвет. Чтобы сменить цвет, используйте колесо прокрутки, удерживая shift, либо щёлкните правой кнопкой без цели.

## Улучшения

Приклады с краской поддерживают следующие [улучшения](upgrade_cards.md), вставляемые через <ItemLink id="cell_workbench" />:

*   <ItemLink id="equal_distribution_card" /> выделяет одинаковое количество байтового пространства ячейки каждому типу, поэтому один тип не может заполнить всю ячейку
*   <ItemLink id="void_card" /> уничтожает вставляемые предметы, если ячейка полна (или выделенное пространство этого типа в
    случае карты равного распределения). Будьте осторожны и задайте разделение!
*   <ItemLink id="energy_card" /> для увеличения ёмкости батареи
