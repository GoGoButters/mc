# Крошечный ТНТ

<BlockImage id="tiny_tnt" scale="8" />

Маленький ТНТ для маленьких взрывов. Полезен для создания пар <ItemLink id="quantum_entangled_singularity" />.

Повреждение блоков от него можно отключить в конфиге, чтобы можно было создавать сингулярности без возможности
гриферства, если вы хотите отключить ТНТ и криперов на вашем сервере.
