# МЭ-Накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

Накопитель — это [устройство](../ae2-mechanics/devices.md), в которое вы вставляете свои [ячейки хранения](storage_cells.md), чтобы использовать их для
[сетевого хранения](../ae2-mechanics/import-export-storage.md). У него есть 10 слотов, в каждый из которых помещается ячейка.

Если по какой-то причине захотите, можете вталкивать и выталкивать ячейки из его инвентаря любой предметной логистикой, например воронками или шинами AE2.

Его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Светодиоды состояния ячеек

На ячейках в накопителе есть светодиод, показывающий их состояние:

| Цвет  | Состояние                                                                        |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный  | Пустая                                                                             |
| Синий   | Имеет некоторое содержимое                                                                |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) заполнены, новые типы добавить нельзя     |
| Красный    | [Байты](../ae2-mechanics/bytes-and-types.md) заполнены, больше предметов вставить нельзя |
| Чёрный  | Нет питания или накопитель не имеет [канала](../ae2-mechanics/channels.md)                 |

## Приоритет

Приоритеты можно задать, щёлкнув по гаечному ключу в правом верхнем углу интерфейса.
Предметы, поступающие в сеть, первым делом будут направляться в хранилище с наивысшим приоритетом. Если два хранилища или ячейки имеют одинаковый приоритет,
то при наличии предмета в одном из них предпочтение будет отдано этому хранилищу перед любым
другим. Любые [разделённые](cell_workbench.md) ячейки считаются уже содержащими предмет
при одинаковой группе приоритета с другими хранилищами. Предметы, удаляемые из хранилища, будут
извлекаться из хранилища с наименьшим приоритетом. Благодаря этой системе приоритетов по мере добавления и извлечения предметов
из сетевого хранилища хранилища с более высоким приоритетом будут заполняться, а с более низким — опустошаться.
