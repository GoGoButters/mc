# Кабельный Якорь

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы, устанавливаемые на кабель, которые можно использовать, чтобы предотвращать соединения кабелей, создавать лестницы из кабелей или делать так, чтобы кабель выглядел
подключённым к окружающим стенам. Также используются для крафта <ItemLink id="facade" />.

Кабельные якоря предотвращают образование соединений на той стороне, на которой они установлены.

По ним можно забираться, как по лестнице.
