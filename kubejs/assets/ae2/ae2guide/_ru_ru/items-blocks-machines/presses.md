## Пресс для имени

Пресс для имени можно использовать в высекателе для именования предметов, аналогично наковальне.

Для крафта щёлкните правой кнопкой мыши по <ItemLink id="certus_quartz_cutting_knife" /> или <ItemLink id="nether_quartz_cutting_knife" />
и вставьте слиток металла, затем вам нужно будет ввести имя, которое вы
хотите нанести на пластину, после чего просто извлеките готовую пластину. В высекателе можно использовать одну или две пластины за раз:
если использовать две пластины, имя будет напечатано комбинацией обоих имён — сначала верхний слот, затем нижний.
