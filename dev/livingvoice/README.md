# Living Voice (серверный мод «Живого мира»)

Голосовые разговоры с жителями MCA и колонистами Living Colonists через Simple Voice Chat.

- Игрок говорит, удерживая кнопку голосового чата. Фраза распознаётся сервисом STT и уходит тому, кого игрок
  назвал по имени (в т.ч. английское имя по-русски: «Джейлин» — Jalynn) или профессии («эй, строитель!»),
  иначе — тому, на кого он смотрит. Если игрок смотрит на собеседника, обращение засчитывается только в начале фразы.
- Колонисты отвечают голосом (TTS) через голосовой чат; жители MCA озвучиваются своей realtime-озвучкой.
- Только сервер. Настройки: `config/livingvoice-common.toml` (адреса STT/TTS с токеном — в сборку не класть).
- Отладка: `/livingvoice selftest <текст>`, `/livingvoice test <житель> <фраза>`.

Сборка: положить в `libs/` jar-ы livingcolonists, mca, minecolonies, structurize (только для компиляции), затем
`./gradlew build` (через прокси: `JAVA_TOOL_OPTIONS=-Dhttps.proxyHost=... -Dhttps.proxyPort=...`).
