# Установка клиента «Живой мир»

Сборка: Minecraft **1.21.1**, NeoForge **21.1.265**, ~150 модов.
Источник сборки: `https://gogobutters.github.io/mc/pack.toml` — моды обновляются сами перед каждым запуском.

## Установщик (Windows, проще всего)

Скачайте [`dist/ZhivoyMir-Setup.exe`](../dist/ZhivoyMir-Setup.exe) и запустите. Права администратора не нужны.

> **SmartScreen.** Файл не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер».
> Нажмите **«Подробнее» → «Выполнить в любом случае»**.

### Режим «Всё в одном» (рекомендуется)

Для тех, у кого ещё нет лаунчера. Установщик:

1. скачивает **PolyMC 8.1 Portable** и **Java 21 (Eclipse Temurin)** с их официальных адресов на GitHub
   и сверяет контрольные суммы SHA-256 (около 90 МБ);
2. настраивает лаунчер: русский язык, Java из папки установки, без мастера первого запуска;
3. создаёт сборку **Minecraft 1.21.1 + NeoForge 21.1.265** — игру и загрузчик лаунчер скачает сам при первом запуске;
4. включает автообновление модов перед каждым запуском;
5. кладёт `servers.dat` — сервер «Живой мир» уже в списке;
6. ставит на рабочий стол ярлык **«Живой мир»**. При первом запуске он открывает окно, где нужно ввести ник
   и нажать «Играть»; дальше ярлык запускает сборку сразу.

Папка по умолчанию — `%LOCALAPPDATA%\ZhivoyMir`. Можно выбрать другую, но она должна быть пустой
(или папкой прежней установки — тогда установщик её обновит). Установка портативная: папку можно
перенести или записать на флешку целиком.

Удаление — `Удалить Живой мир.exe` в папке установки: удаляет папку вместе с мирами, настройками и скриншотами.

Первый запуск скачивает Minecraft, NeoForge и моды — 5–10 минут, дальше — секунды.
В главном меню игры нажмите **«▶ Играть: Живой мир»**.

### Режимы для уже установленного лаунчера

- **Prism Launcher** — установщик добавляет сборку в его папку `instances` (по умолчанию `%APPDATA%\PrismLauncher\instances`).
- **PolyMC** — то же для `%APPDATA%\PolyMC\instances`.

Лаунчер должен быть хотя бы раз запущен. Java 21 в этом случае берёт сам лаунчер (в Prism она обычно скачивается автоматически).
Деинсталлятор `Удалить Живой мир.exe` лежит в папке сборки и удаляет только её.

## Ручная установка (любой лаунчер с поддержкой pre-launch command)

1. Создайте сборку: Minecraft **1.21.1**, загрузчик **NeoForge 21.1.265**. В PolyMC компонент NeoForge — `net.neoforged.neoforge`.
2. Положите [`packwiz-installer-bootstrap.jar`](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest/download/packwiz-installer-bootstrap.jar) в папку игры (`.minecraft` сборки).
3. Пропишите команду перед запуском (Pre-launch command):
   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar --multimc-folder nommc https://gogobutters.github.io/mc/pack.toml
   ```
   В Prism/PolyMC: `Изменить → Настройки → Свои команды → Команда перед запуском`.
   `--multimc-folder nommc` не даёт packwiz переписывать компоненты сборки: иначе в PolyMC он добавляет
   несовместимый компонент `net.neoforged`, и игра запускается без NeoForge.
4. Java 21, память 8 ГБ (если в компьютере всего 8 ГБ ОЗУ — 5–6 ГБ).

## Аккаунт и ник

**«Всё в одном»:** при первом запуске ярлыка открывается окно «Как тебя зовут, странник?». Ник — 3–16 символов:
латинские буквы, цифры и `_`. Окно записывает автономный аккаунт в `accounts.json` лаунчера и запускает игру;
дальше окно не появляется. Сменить ник — в лаунчере («Аккаунты») или запустить `java\bin\javaw.exe -jar ZhivoyMir.jar --setup`
из папки установки. Окно — `ZhivoyMir.jar` (исходники `dev/launcher`).

**Свой лаунчер:** аккаунт добавляется в окне лаунчера; при первом запуске он сам попросит его добавить.

Ник закрепляется на сервере паролем при первом входе (мод Nedologin): клиентская часть
сама придумывает и хранит пароль. Под чужим ником войти не получится. Забыли пароль — админ
(`vadim`) сбрасывает его командой `/nedologin unregister <ник>`.

Белый список на сервере выключен: войти может любой, ник защищает Nedologin.

## Настройки игры при первой установке

Русский язык, диктор выключен (и его клавиша Ctrl+B), без экрана специальных возможностей при первом запуске.
**Чат открывается клавишей Caps Lock** (а не T): регистр букв при этом не переключается — мод zmclient
возвращает Caps Lock обратно. Эти настройки (`options.txt`) кладутся только при первой установке; у тех, кто уже
играет, чат меняется в «Настройки → Управление».

## Сервер

`globe.r2d2.dedyn.io` — уже в списке серверов, и на кнопке «▶ Играть: Живой мир» в главном меню.

## Голосовой чат

Simple Voice Chat: клавиша **V** в игре. Нужен UDP-порт 24454 (на сервере проброшен).
Если голоса нет — проверьте, что Windows разрешил игре доступ к сети (частная сеть).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Установщик: «Не удалось скачать» / «контрольная сумма» | Проверьте интернет и запустите установщик ещё раз |
| «Не удалось обновить» при запуске | Проверьте интернет; в лаунчере откройте лог сборки — там видна ошибка packwiz |
| Сервер пишет «install NeoForge», во вкладке «Версия» красная строка `net.neoforged` | Сборка поставлена старым установщиком: запустите новый поверх (миры сохранятся) |
| Игра падает на загрузке | Убедитесь, что версия 1.21.1 и **NeoForge 21.1.265**, а не Forge/Fabric, и Java 21 |
| Не видно сервера | Пропишите адрес вручную: `globe.r2d2.dedyn.io` |
| Мало FPS | Уменьшите дальность Distant Horizons (кнопка DH в настройках графики) или выключите его там же; Sodium уже стоит |
| Не хватает памяти / компьютер тормозит целиком | Установщик выставляет 8 ГБ. Если в компьютере 8 ГБ ОЗУ — в лаунчере «Изменить → Настройки → Java» поставьте максимум 5–6 ГБ |
