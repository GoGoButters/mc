# Установка клиента «Живой мир»

Сборка: Minecraft **1.21.1**, NeoForge **21.1.265**, ~110 модов.
Источник сборки: `https://gogobutters.github.io/mc/pack.toml` — моды обновляются сами при каждом запуске.

> Сборка ставится в **ваш** лаунчер. Аккаунт Minecraft вы заводите в лаунчере сами.

## Вариант 1 — установщик (Windows, проще всего)

Скачайте [`dist/ZhivoyMir-Setup.exe`](../dist/ZhivoyMir-Setup.exe) и запустите. Установщик:

1. спрашивает **ник**;
2. находит `instances` у Prism/MultiMC (или папку `.minecraft`, если её указать);
3. создаёт сборку: **Minecraft 1.21.1 + NeoForge 21.1.265** скачает сам лаунчер при первом запуске;
4. кладёт в папку игры `servers.dat` (сервер «Живой мир» уже в списке) и `packwiz-installer-bootstrap.jar`;
5. включает автообновление модов перед запуском игры;
6. ставит ярлык «Живой мир» на рабочий стол.

Дальше: открыть лаунчер → добавить аккаунт с ником → выбрать «Живой мир» → **Играть**.
Первый запуск скачивает моды (1–3 минуты), дальше — секунды.

**Какие лаунчеры подходят:** Prism Launcher, MultiMC (создаётся готовая сборка) — рекомендуется.
Любой другой (ATLauncher, CurseForge, GDLauncher, официальный) — установщик работает в режиме «папка игры»: указываете его `.minecraft`.
Понадобится **Java 21** ([Adoptium](https://adoptium.net)), если лаунчер её не приносит сам.

## Вариант 2 — портативная установка вручную

1. Скачайте [`dist/ZhivoyMir-Portable.zip`](../dist/ZhivoyMir-Portable.zip) и распакуйте в папку игры (`.minecraft` вашего лаунчера или на флешку).
2. Запустите `Play.bat` — он скачает моды и конфиги в эту папку.
3. В лаунчере пропишите команду перед запуском (Pre-launch command):
   ```
   "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://gogobutters.github.io/mc/pack.toml
   ```
   В Prism/MultiMC: `Edit → Settings → Custom commands → Pre-launch command`.
4. Версия игры: **1.21.1**, загрузчик **NeoForge 21.1.265**. Память 6–8 ГБ.

## Ник

Ник задаётся в лаунчере. В Prism/MultiMC при отсутствии аккаунта Microsoft:
`Accounts → Manage Accounts → Add → Offline` и вписать ник.

Ник закрепляется на сервере паролем при первом входе (мод Nedologin): клиентская часть
сама придумывает и хранит пароль. Под чужим ником войти не получится. Забыли пароль — админ
(`vadim`) сбрасывает его командой `/nedologin unregister <ник>`.

Доступ на сервер — по белому списку. Чтобы добавить друга, админ выполняет:
```
/whitelist add <ник>
```

## Сервер

`globe.r2d2.dedyn.io` — уже в списке серверов, и на кнопке «▶ Играть: Живой мир» в главном меню.

## Голосовой чат

Simple Voice Chat: клавиша **V** в игре. Нужен UDP-порт 24454 (на сервере проброшен).
Если голоса нет — проверьте, что Windows разрешил игре доступ к сети (частная сеть).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Не удалось обновить» при запуске | Проверьте интернет и Java 21; запустите `Play.bat` вручную — он покажет ошибку |
| Игра падает на загрузке | Убедитесь, что версия 1.21.1 и **NeoForge 21.1.265**, а не Forge/Fabric |
| Не видно сервера | Пропишите адрес вручную: `globe.r2d2.dedyn.io` |
| «Не в белом списке» | Попросите админа добавить ник командой выше |
| Мало FPS | Поднимите память до 8 ГБ; шейдеры не входят в сборку, Sodium уже стоит |
