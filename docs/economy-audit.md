# Аудит экономики изумрудов (2026-11-08)

Источники: jar-файлы и конфиги тестового сервера 192.168.1.239 (`/opt/minecraft/server`).

## Источники изумрудов

| Источник | Сейчас | Оценка |
|---|---|---|
| **Налоги War 'N Taxes** | Каждые 60 мин с каждой построенной постройки: `floor((база + прибавка × уровень) × довольство[0,5…1,5] × (1 + бонус улучшений))`. База 5–25, прибавка 1–10 (ратуша 20 + 8/ур.). Потолок накопления 10 000 | **Сломано.** Колония первого дня (ратуша, строитель, 3 дома, ферма, лесоруб, склад) ≈ 100/ч без участия игрока; средняя (25 построек ур. 3) ≈ 500–800/ч |
| Просеиватель MineColonies | Гравий + железная сетка (ур. 4): изумруд 1/100; алмазная (ур. 5): 2/118 | Норма: нужен гравий и прокачанная постройка |
| Торговля с жителями (MCA = ванильные сделки) | Палки, пшеница, бумага и т. п. → 1 изумруд; 12–16 сделок на жителя, пополнение 2 раза в игровые сутки | Норма: классика, ограничено числом жителей |
| Bountiful | Награда 1–4 изумруда (ценность 1000 за изумруд; 64 земли ≈ 1). Доска обновляется каждые 45 с | Терпимо; частое обновление позволяет перебирать лёгкие задания |
| Руда: Create (1,75 с руды), Mekanism (2 с руды), Spelunkery (осколки) | Конечный ресурс | Норма |
| Нуклеосинтезатор Mekanism | Антиматерия → изумруд | Норма: поздняя игра, очень дорого |
| Colonist Thieves | Добыча кражи: 1–3 захода, изумруды 1–4 (вес 10) | Норма: стоит репутации |
| Дары бога | До 5 изумрудов за дар, редко | Норма |
| Сундуки в данжах и деревнях | Единицы | Норма |
| Trade Post | Свои монеты `mctp_coin`; изумруды в монеты не превращаются, и обратно тоже | Не влияет |
| Numismatics | Стартовых монет нет | Не влияет |
| Крафт из дешёвого сырья | Не найден (12 рецептов, все из руды, осколков или самих изумрудов) | Норма |

## Расходы

Рекруты: 4–20 за наём, оплата выключена. Захват чанков Recruits: 64 + 15 за чанк. Фракция Recruits: 10. Приглашение zmbridge: 1. Дары богу. Исследования MineColonies (например, «Чёрный рынок» — 48). Наём гостей таверны. War 'N Taxes: содержание военных построек (казармы 15 + 5/ур., башня 10 + 3/ур.), фракция 5000, шпионаж 100–2500, вложения 500–2000, выкуп 100–10 000, военная казна до 25 000.

Расходы War 'N Taxes рассчитаны на налоговый поток ×10 от разумного, поэтому их режем так же, как налоги.

## Предложение

**Цель:** ранняя колония ≈ 5–10/ч, средняя ≈ 40–60/ч, поздняя ≈ 120–170/ч (× довольство). Активный заработок (торговля, задания) сопоставим с пассивным на старте.

### War 'N Taxes (`config/warntax/minecolonytax.toml`)
Округление вниз идёт по каждой постройке, поэтому дробная база даёт 0 — значения подобраны с учётом этого.

| Группа | База | Прибавка | Ур.1 → ур.5 |
|---|---|---|---|
| Ратуша | 3 | 1 | 4 → 8 |
| Университет, больница, мистическое место, большой карьер | 2 | 1 | 3 → 7 |
| Остальные производственные | 1 | 0,5 | 1 → 3 |
| Дом, тайник, почтовый ящик, компостер, кладбище | 0 | 0,5 | 0 → 2 |

Содержание: казармы 2 + 1, казарменная башня 2 + 1, сторожевая башня 1 + 0,5, стрельбище и академия 1,5 + 0,5.

Суммы ÷10: `MaxTaxRevenue` 10000 → 1000, `DebtLimit` 2000 → 200, `TaxStealPerGuard` 200 → 20, `FactionCreationCost` 5000 → 500, `TradeRouteMaintenanceCost` 25 → 3, шпионаж 100/1500/2500/1000 → 10/150/250/100, военная казна: расход 10 → 1 в мин., вместимость 25 000 → 2500, выкуп 100–10 000 → 10–1000, вложения 1500/500/2000/1500 → 150/50/200/150.

### Villager Recruits (`config/recruits-server.toml`)
- Оплата включена: `RecruitsPayment = true`, 1 изумруд каждые 20 мин (3/ч за бойца). Берётся из инвентаря рекрута или его сундука-обеспечения; без оплаты падает мораль.
- Наём ×2: рекрут 8, лучник 12, арбалетчик 16, щитоносец 20, всадник 40, кочевник 38.

### Bountiful (`config/bountiful/bountiful.json`)
- `updateFrequencySecs` 45 → 300: задания нельзя перебирать без конца.

### Без изменений
Просеиватель, торговля с жителями, руда, Mekanism, воры, дары бога, приглашение zmbridge.

### Хранение конфигов
Эти три серверных конфига кладём в `config/` сборки: тогда `packwiz -s server` развернёт их на сервере из репозитория. Клиенту они не мешают.
